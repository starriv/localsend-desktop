# LocalSend desktop icon

A new vector interpretation of LocalSend's central node and segmented orbit:
four rounded, broad arcs surround a filled node on a teal background. The
foreground uses filled SVG outlines with no baked-in shadows or highlights.
Apple's renderer supplies the glass material, light, masking, and depth.

- `AppIcon.icon`: editable Icon Composer document, with separate orbit and
  node layers and default/dark background annotations. Other appearances are
  derived by the system from the same structure.
- `mark.svg`: flat monochrome geometry for reuse outside Apple platforms.
- `../src/ui/icons.rs`, `IconName::LocalSend`: the same mark drawn directly by
  the UI canvas and AppKit at their backing scale for crisp small icons.
- `../assets/icon.png`: 1024 px rendered fallback for Windows/Android and
  tools that require a PNG. It is not the native macOS icon source.

Regenerate the artwork and fallback on a Mac with Xcode and Icon Composer:

```sh
./scripts/render-icon.sh
```

`draw-icon.py` uses only Python's standard library. `render-icon.sh` invokes
Apple's Icon Composer renderer, then preserves its colors in sRGB. No image
generation API, bitmap tracing, or enlargement of the upstream PNG is used.

`scripts/package-macos.sh` compiles `AppIcon.icon` with `actool` and installs
`Assets.car`, `AppIcon.icns`, and the corresponding Info.plist keys before
signing. Current macOS uses the layered asset; older supported macOS versions
use the compatibility `.icns` generated by Apple's tool.

References: [Apple app icon guidelines](https://developer.apple.com/design/human-interface-guidelines/app-icons),
[Icon Composer](https://developer.apple.com/icon-composer/), and the
[LocalSend identity](https://github.com/localsend/localsend/tree/main/app/assets/img).
